# Help

Welcome to your5e, a toolkit for tabletop roleplayers and game masters. This
site provides tools for organising your campaigns, keeping notes, and sharing
resources with your group.

Everything here is designed to work without requiring JavaScript, so you can
use it on any device, in any browser. Your notes are stored as plain Markdown
files, which means you always have access to your own content in a format you
can read and use elsewhere.
